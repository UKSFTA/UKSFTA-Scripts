# UKSFTA Scripts

Centralised logic framework and function library for UKSFTA projects.

Contains all SQF-based logic, registered in the engine's Function Library.

## Features

- Global Functions: Registered under the `UKSFTA_fnc_` namespace.
- CBA Integration: Integrated with the CBA Macro system.
- Headless Validation: CI testing via `sqflint` and `hemtt check`.

## Technical

- VFS Prefix: `z\\uksfta\\main`
- Dependency: CBA (Community Base Addons).
- Build System: Automated via [UKSFTA-Tools](https://github.com/UKSFTA/UKSFTA-Tools).
